​1. About the Project & Storyline
​Pretty Crown Barber & Beauty Salon is a salon located in Polokwane, Limpopo Province. The salon offers hair, barber, and nail services for both men and women.
​The goal of this website is to give customers an easy way to:
​Learn about the salon and the team.
​View all services and prices.
​Search and filter services by name, category, or price.
​Check if the salon is open right now.
​Send an online enquiry or booking request.
​Find the salon on an interactive map.

​2. Website Structure & Files
​The project is built using basic web technologies: HTML for the content, CSS for the styling, and JavaScript for interactivity.

File         |     Name               |   What it Does
-------------|------------------------|------------------------------------------------------------------------------------------------
index.html        The homepage.         Contains the welcoming section, an open/closed status badge, service highlight cards, and a photo                                         gallery with a popup image viewer (lightbox).
---------------------------------------------------------------------------------------------------------------------------------------
about.html        The About Us page.    Contains clickable tabs for our story, mission, and team, plus expandable FAQ questions.
---------------------------------------------------------------------------------------------------------------------------------------
services.html     The Services page.     Displays all services with a search bar, category filters, price sorting, and a full price                                                list table.
---------------------------------------------------------------------------------------------------------------------------------------
enquiry.html      The Enquiry page.      Contains an interactive form where users can ask about prices or request a booking slot.
----------------------------------------------------------------------------------------------------------------------------------------
contact.html      The Contact page.      Displays salon details, an interactive Leaflet map, and a contact form that prepares email                                                drafts.
----------------------------------------------------------------------------------------------------------------------------------------
style.css                                The single CSS file that controls all colors, fonts, margins, buttons, and mobile responsiveness                                          across all pages.
----------------------------------------------------------------------------------------------------------------------------------------
script.js                                The single JavaScript file that runs all interactive features like search, forms, tabs, map, and                                          gallery popups.
----------------------------------------------------------------------------------------------------------------------------------------
robots.txt                               A simple text file that tells search engines (like Google) that they can read all pages on the                                            site.
----------------------------------------------------------------------------------------------------------------------------------------
sitemap.xml                              An XML file that lists all 5 website pages so search engines can easily find and list them.
----------------------------------------------------------------------------------------------------------------------------------------
Mypictures/                              A folder containing all pictures used on the website.
